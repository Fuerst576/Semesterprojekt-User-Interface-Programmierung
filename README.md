# Semesterprojekt-User-Interface-Programmierung
 Wir möchten ein ansprechendes Frontend für eine Kurzfilm-Review-Plattform entwickeln. Auf der Plattform können Nutzer:innen eigene Kurzfilme anlegen und Bewertungen dazu verfassen. Die Kurzfilme lassen sich nach Genre filtern, und jede:r Nutzer:in kann sie in einer persönlichen Sammlung speichern.
